{ Portfolio }

Tous Refonte Personnel Site internet Portfolio

Contexte

Mon ancien portfolio ne me représentait plus. Il était certes fonctionnel, mais il manquait ce quelque chose qui fait qu'on s'en souvient. Cette refonte n'est pas seulement une mise à jour technique, c'est un changement total. J'ai voulu créer un espace plus créatif, avec une identité visuelle et des couleurs qui s'assument, et une atmosphère qui s'impose dès la première seconde.

Direction artistique

Pour cette V5, j'ai voulu pousser l'identité visuelle plus loin, avec une direction artistique plus futuriste et cyberpunk, sans changer forcément ma stack technique. Cette refonte poursuit plusieurs objectifs :

Une identité visuelle forte : sortir d'un format de portfolio classique pour créer un espace qui marque les esprits dès la première seconde.
Un terrain d'expression créative : montrer que je ne me limite pas à l'exécution, mais que je sais imaginer et porter une direction artistique complète.

Process & stack technique

La stack technique reste lamême. Ce qui change, c'est la rigueur : un code plus structuré, plus pensé, plus abouti.

HTML : pour la structure.
Sass : pour le style.
JavaScript : pour les interactions et les effets.
Bootstrap : pour le responsive.
